# Addie 18

"18 songs I think you should meet." A liner-notes page for Addie's 18th birthday card, reached by QR code.

- Song list and notes live in `app/songs.ts`. The notes are Cara's and are locked.
- To add Spotify, paste the playlist link into `SPOTIFY_URL` in `app/songs.ts`. The button appears on its own.
- The URL is printed on cardstock. Do not rename the Vercel project or change the domain.

Next.js + Tailwind, deployed on Vercel.
